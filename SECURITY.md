# Security policy

For a suspected vulnerability, use
[Report a vulnerability](https://github.com/ahmad-fatayerji/veil/security/advisories/new)
to contact the maintainer privately through GitHub. Include the exact Veil
version, affected component, impact, and reproducible steps using fictional
content. Do not include live invitations, credentials, private documents, or
signing material in a public issue.

Use the latest stable release when checking whether an issue still reproduces.
Beta releases are test candidates. Do not assume an older release has received
the fixes in a newer version.

See [security and privacy](docs/security.md) for the current encryption,
invitation, credential, capture-exclusion, and updater boundaries. Veil has not
undergone an independent security audit. Ordinary non-sensitive bugs can be
reported through [GitHub issues](https://github.com/ahmad-fatayerji/veil/issues).
