# Veil 0.1.2 — Automated Windows release

Windows x64 P2P test build produced by the private source repository's release workflow and distributed through the public **veil** repository. Includes the per-user installer, signature-verified/version-bound GitHub updater, and update installation guard for active document sessions and LAN hosts. Publishing refuses to replace an existing released version.

Both participants install Veil and exchange invitation/response codes privately. Shared editing, named presence and the editable local overlay are included. Optional STUN/TURN settings use servers you configure; no default relay or discovery service. Some networks require a relay, so internet connectivity is not guaranteed. GitHub distributes the application and does not handle peer signaling.

Documents are temporary and are lost when ending/leaving/closing. Copy important text before leaving a session to install an update. Local overlay settings are retained. The real signed HTTPS upgrade from 0.1.0 to 0.1.1 was verified locally, including restart and preferences. Same-PC P2P tests passed; different-network and self-hosted TURN tests remain manual. A clean Windows VM test remains separate from local installer acceptance.

Windows installer has no Authenticode publisher certificate; unknown-publisher warnings may appear. Updater signatures are separate from Windows publisher trust. Windows 10/11 x64; setup downloads WebView2 if missing. See **TESTING.md** attached to this release.
