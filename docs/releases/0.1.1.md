# Veil 0.1.1 — Installer and signed updates

Windows x64 P2P test build with a per-user installer, public GitHub download/update feed, and an explicit **App updates** panel. Updater packages are signature-verified and bound to their release version; HTTPS is required for the feed and downloads. Installation is refused while a document session or LAN host is active, and local overlay preferences are saved before restart.

Both participants install Veil, then exchange an invitation and response privately. Includes shared editing, named presence, editable local overlay, optional configurable STUN/TURN, and authenticated LAN/browser mode. No default signaling service, discovery server, relay, accounts, purchased domain or participant cap.

Documents remain temporary: copy text you want to keep before ending/leaving/closing. Direct WebRTC sync and overlays have been verified locally, but different internet networks and self-hosted TURN still need tester validation. Installer is not Windows Authenticode-signed; unknown-publisher warnings are possible. Updater signatures do not confer Windows publisher trust. Setup downloads WebView2 if missing. Windows 10/11 x64.

See **TESTING.md** attached to this release for connection steps, known limits and useful test reports.
