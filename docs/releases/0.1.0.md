# Veil 0.1.0 — P2P test build

First Windows x64 installer for testing desktop peer collaboration. Both people install Veil and exchange invitation/response codes. Includes encrypted WebRTC data channels, shared editing/presence, local editable overlay, optional configurable STUN/TURN, and retained authenticated LAN/browser mode.

App updates use signed packages from the public release repository. Check manually under **App updates**. Installation is blocked while a session is open; copy important text before ending it. Overlay preferences are retained. Documents remain in memory and are lost on ending/leaving/closing.

Direct transport has been tested with three native desktop instances locally, including fragmented updates, offline merge and overlay editing. Different internet networks and a self-hosted TURN server still need tester validation. No default discovery service, relay, participant cap, accounts or purchased domain.

Installer is not Windows Authenticode-signed; unknown publisher warnings are possible. Updater signatures are separate and do not confer Windows publisher trust. Windows 10/11 x64 only. WebView2 is required and setup downloads it if missing.
