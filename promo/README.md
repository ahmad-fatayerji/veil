# Veil promo video

A 31-second promo built with [Remotion](https://www.remotion.dev) from real captures of
the Veil desktop app. It is a standalone npm project, outside the pnpm workspace.

## Preview and render

```console
cd promo
npm install
npm run dev      # Remotion Studio; prepares assets first
npm run render   # out/veil-promo.mp4
```

`npm run setup` (run automatically before `dev` and `render`) prepares the assets that
are not committed:

- `public/product/veil-icon.png`, copied from `packages/ui/src/assets`.
- `public/music/veil-theme.wav`, the original music bed generated by
  `music/compose.mjs` (120 BPM; its sections line up with the cuts).
- `public/sfx/*.wav`, downloaded from Remotion's sound effect library.

Remotion is free for individuals and small teams; larger companies need a
[company license](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md).

## Captured footage

Everything in `public/capture` comes from the real app; no interface is mocked.
`capture/capture.mjs` follows the `scripts/test-create-share-join.mjs` harness:

- Three debug instances with disposable profiles (Alex hosts in dark, Sam and Priya
  join in light) are driven over WebView2's DevTools protocol.
- Sharing uses a loopback-only `veil-server`, never the public servers, and the script
  stops if an invite link points anywhere else.
- Only the app's own web content is recorded (CDP screencast), not the desktop.
  Invite links are blurred.
- Each clip has a JSON log of pointer events that drives the video's cursor, click
  ripples and click sounds.

`capture/exclusion.mjs` is a separate capture-exclusion check. It pins a known slide
window directly under the overlay, confirms through Windows that the overlay is the
top window there, and records the region with ffmpeg's GDI capture. It keeps the
result only if the recording matches the slide, so nothing else on the desktop can
leak into the media. This shows one capture method on one machine; capture exclusion
is best effort and never universal.

To capture again on Windows (needs ffmpeg, ffplay and ImageMagick on `PATH`):

```console
pnpm dev:multi 1                                   # from the repo root: builds the debug app, then close it
$env:VEIL_SERVER_BINARY = "<path>\veil-server.exe" # veil-server built at the CI-pinned commit
npm run capture
npm run capture:exclusion
```

These scripts open real windows on your desktop while they run. `capture/reencode.mjs`
re-encodes clips from a previous run's saved frame timings.
